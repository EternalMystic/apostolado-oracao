APOSTOLADO DA ORAÇÃO – Sistema de Gestão
Paróquia São Jorge · Nova Odessa – SP
=========================================

INSTALAÇÃO (primeira vez)
  1. Duplo clique em INSTALAR.bat
  2. Aguarde instalação do Python/pacotes

USO DIÁRIO
  1. Duplo clique em INICIAR.bat
  2. O navegador abrirá o painel Streamlit

BACKUP
  - Automático antes de cada gravação (pasta backups/)
  - BACKUP_AGORA.bat – cópia manual imediata
  - INSTALAR_BACKUP_AUTOMATICO.bat – agenda backup diário (Windows)

DADOS
  data/apostolado.xlsx – planilha principal (8 abas)
  Recriar do zero: Configurações → Recriar Excel

RELATÓRIO PDF MENSAL (opcional)
  Requer R instalado + ggplot2
  Rscript r_scripts/relatorio_mensal.R

ROTA OTIMIZADA (opcional)
  COMPILAR_RUST.bat
  rust_utils/route_optimizer/target/release/route_optimizer.exe
